# SocialDash - React Social Media Dashboard

A fully responsive, multi-page social media dashboard built for Month 2 of the Web Development Internship at The Developers Arena. 

## Project Overview & Architecture
This project demonstrates a modern frontend React architecture:
* **Component-Based UI:** The interface is broken down into modular, reusable building blocks (`Card`, `Post`, `Button`, `Notification`) to keep the codebase DRY and maintainable.
* **Client-Side Routing:** Implemented `react-router-dom` to enable seamless navigation between the Home feed, Profile, and Notifications pages without page reloads.
* **State Management:** Utilized React `useState` hooks to manage interactive elements like the post Like buttons and the global Dark/Light mode theme toggle.
* **Dynamic Styling:** Integrated CSS Modules alongside global state to ensure clean, scoped styling that adapts perfectly to theme changes and mobile viewports.
